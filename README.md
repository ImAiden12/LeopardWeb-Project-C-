# LeopardWeb-Project-C-
LeopardWeb is Wentworth’s online portal where students and professors can access course registration, class schedules, grades, academic records, and other important information. In my Applied Programming Concepts class, I was tasked to work with 2 of my peers to redesign LeopardWeb using C++ programming to create the backend functionality, and SQL to create the database. The way we planned to do this was by creating the program separately from the Database, and then combine the two to create the final product. First, we started by creating the main functionality of the program, allowing the user to put in a hard-coded username and password to enter the main menu. We then created the database with tables that I needed, including login information for each user, scheduling information for each user, and rosters for each class. Then, we changed the functions in the original program to be able to interact with the database, either storing/updating information into the database, or reading information from the database. The original program was text based, but using Windows Forms, we created a GUI for the final product of the program. By the end, we had successfully created a program that allowed students and instructors to create and customize a schedule for themselves, view the schedule that they created, and view the roster of a class; all of these functions are core functions of the real LeopardWeb.
